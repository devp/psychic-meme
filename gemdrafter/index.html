    What this is
    
      
    
        A drafting table for gemtext:
        write a post, see it the way a client will, and get the
        index.gmi that links them all up. Offline, installable,
        nothing leaves the phone.
      
    
      
    The format, in full
    
      
      
        
    • => URL label — a link. The only kind there is; no inline anchors.
      • 
        
    • # ## ### — three heading levels, no fourth.
      • 
        
    • * item — a list item. The space is required.
      • 
        
    • > quoted — a quote line.
      • 
        
    • ``` — toggles preformatted; text on the toggle line is alt text.
      • 
        
    • Anything else is a text line, and a text line is a whole paragraph.
      • 
      
    
      
    Writing for smol.pub
    
      
      
        
    • The slug is the post: devp.smol.pub/<slug>, and
            the name of the file you upload. It follows the title until you set
            it, and then it stays put — renaming a post shouldn't move its URL.
      • 
        
    • Copy and Download give you the file
            smol.pub's uploader wants: the title on line one, a blank line, then
            the body. No extension, because the filename is the slug.
      • 
        
    • smol.pub renders gemtext to HTML and a gophermap for you, so what the
            preview tab shows is the shape all three get.
      • 
      
    

      
    Autosave, checkpoints, trash
    
      
      
        
    • Typing saves itself after a pause; the line under the box says when.
      • 
        
    • While you're typing on a phone, the header, title, slug and buttons
            fold away so the text gets the room. Dismiss the keyboard to get
            them back.
      • 
        
    • Coming back to a post after five minutes away keeps a
            checkpoint of what it was before you started. So does
            the Checkpoint button. The last 20 are kept.
      • 
        
    • Restore checkpoints the current text first, so it's
            always undoable.
      • 
        
    • Deleting a post puts it in the trash with its history.
            Nothing leaves storage until you delete it from there.
      • 
      
    

      
    What it won't do
    
      
      
        
    • Upload. It drafts. smol.pub's own uploader takes the file
            this gives you, and a browser can't post to smol.pub on your behalf
            anyway — your session cookie belongs to their origin, not this one.
      • 
        
    • Draft-vs-published. Every post you've written a word in
            is in the index. A drafter that hides posts from its own index has
            become a CMS.
      • 
        
    • Reorder. The list is creation order, newest first, and an
            edit doesn't move it.
      • 
        
    • Autocomplete or syntax highlighting in the box. A dumb textarea
            has one failure mode.
      • 
      
    
      
    Where things are
    
      
      
        
    • lib/gemtext.js — the format as data: parse, lint, slug, index. Pure.
      • 
        
    • components/gem-preview.js — a component built to travel: give it
            a text property, it renders gemtext, and it imports no app state.
      • 
        
    • state.js — every store this app has.
      • 
        
    • app.js — all the wiring, in the open.
