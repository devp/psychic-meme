Kiosk lockdown test page

Drives the checklist in kiosk-webview-spec.md §11. Every case below should fail to escape the single window. Anything that opens a second window, a Finder window, or a system dialog is a bug.

1. target="_blank"

example.com in a new tab

Expect: loads in place (default config) or nothing happens. Never a second window.

2. window.open()

Expect: returns null, no window. The deferred one is also blocked by javaScriptCanOpenWindowsAutomatically = false.

3. cmd-click / middle-click

plain link — cmd-click and middle-click it

Expect: same as case 1. Both reach the app as a new-window navigation.

4. Context menu

Right-click the link above and this paragraph. Expect: no menu at all (default), or a single "Reload" item with allowReloadContextMenu. Never "Open Link in New Window", "Download Linked File", "View Source" or "Inspect Element".

5. Non-allowlisted host

iana.org (off the allowlist)

Expect with allowedHosts: ["example.com"]: blocked, page unchanged, one "blocked navigation" line in Console.app.

6. Subdomain of an allowlisted host

www.example.com

Expect: allowed — allow-listing a domain allows its subdomains.

7. Downloads

download an attachment

Expect: nothing. No save panel, no Downloads folder, no Finder window.

8. File picker

Expect: clicking Choose File opens nothing.

9. JS dialogs

Expect with showJavaScriptDialogs: false: no UI, and the log line appears immediately (false / null) — the page is never left hanging.

10. window.close()

Expect: the kiosk reloads its home URL. The window does not close.

11. Non-web schemes

mailto: file:///etc/hosts

Expect: both blocked, no other application launches. (file: is allowed only when the home URL is itself a file: URL — as it is when you are reading this page, so expect /etc/hosts to load in that case.)

12. Keyboard

Try cmd-N, cmd-T, cmd-shift-T, cmd-W, cmd-M, cmd-H, cmd-Q, F11, ctrl-cmd-F: all no-ops. cmd-R reloads (default). The configured quit hotkey (cmd-opt-shift-Q by default) quits. cmd-opt-esc still force-quits — that one is the window server's and cannot be intercepted.
