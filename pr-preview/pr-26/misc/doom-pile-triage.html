DOOM PILE

single-item triage protocol · desk zone edition

Pick up one item. Then answer.
01 · EXISTENCE CHECK
Can you identify what this item actually is?
02 · USE CHECK
Have you used or needed this in the last 12 months?
Or: is there a concrete upcoming moment you'll use it?
03 · VALUE CHECK
Is it replacing it expensive, sentimental, or legally needed?
04 · SENTIMENTAL AUDIT
Does keeping it serve you — or just avoid the decision?
Be honest. "Maybe someday" is the pile's favorite lie.
05 · HOME CHECK
Does this item have a defined home (a spot, drawer, bin)?
06 · PAPER TRIAGE
What kind of document is it?
07 · ACTION CHECK
Can you act on this right now (under 2 min)?
🗑 Trash / Recycle
This item is done. Bin it now — don't put it down first. If it has personal data, shred or delete.
📦 Donate / Rehome
Drop directly into your donation bin or bag. If it's a specific person's item, text them now while you're holding it.
🗂 File It
Goes into the filing system immediately. Key categories for your desk zone: IEP/Reid docs, financial, household, archive. No "to file" pile — file it now.
📋 Capture the Action
Add to Todoist before you set the item down. Give it a due date. Then put the item somewhere intentional (a pending tray) or file it if it's just a reference.
⚡ Do It Now
Two minutes max. Send the text, toss the wrapper, plug in the cord, write the note. Done items don't return to the pile.
✅ Return to Home
Put it away right now — don't set it aside to "put away later." That's how the pile formed.
🕐 Defer with a Date
This item needs a home but you can't create one right now. Capture a task: "Find home for [X]" in Todoist with a due date. Then put it in a clearly labeled holding zone — not back in the pile.
