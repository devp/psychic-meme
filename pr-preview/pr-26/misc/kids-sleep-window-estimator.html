Kids Sleep Window Estimator

Offline-friendly model for estimating overtired / second-wind risk windows. Not a cortisol measurement or medical tool.

Formula

risk_start = anchor + capacity + nap_bonus - sleep_debt - activity - transition

If there is no nap, anchor is wake time and capacity is all-day wake capacity. If there is a nap, anchor is nap end and capacity is post-nap capacity. The model estimates overtired / activated behavior risk, not actual cortisol concentration.
