What this is

A no-build, offline-first, installable web app skeleton. Add it to your home screen, turn on airplane mode, and it still works.

There is no build step. The files you edit are the files that ship. The one generated file is precache-manifest.js: regenerate it with just dev-rebuild; just warnings flags it when stale.

Where things are

  • lib/viewport.js — the mobile keyboard fix. The reason this exists.
  • lib/store.js — localStorage with subscribers, so nothing goes stale.
  • app.js — all the wiring, in the open.
  • components/append-log.js — a component built to travel: it takes properties, imports no app state, and leans on Lit's keyed repeat() so existing entries keep their DOM nodes and a screen reader only hears what's new.
  • vendor/lit.js — Lit, vendored. 17.4KB raw, 6.8KB gzipped.
