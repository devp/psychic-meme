What this is

A no-build, offline-first, installable web app skeleton. Add it to your home screen, turn on airplane mode, and it still works.

There is no build step. The files you edit are the files that ship. The only thing derived from anything else is the precache list in sw.js, and just check fails if it goes stale.

Where things are

  • lib/viewport.js — the mobile keyboard fix. The reason this exists.
  • lib/store.js — localStorage with subscribers, so nothing goes stale.
  • reactive-element.js — ~40 lines of re-render-on-assignment.
  • app.js — all the wiring, in the open.
  • components/append-log.js — a component built to travel: it takes properties, imports no app state, and appends rather than rebuilding so a screen reader isn't re-read the whole log on every line.

The list tab tells you what to change.
