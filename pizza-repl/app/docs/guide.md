# Using this REPL

Type an entry, press **Enter** (or **Run**). **Shift-Enter** adds a line instead. Each entry runs in
the same interpreter, so what you define stays defined until the page reloads.

## The key row

The colored keys above the input insert their character at the caret, without the keyboard's
symbol layer. The gray **⋯** key in the middle opens command shortcuts: the language's own,
then any you add under **Options → Command shortcuts** (comma-separated).

## Completions

Some languages offer completions: after two characters of a name, a strip of chips appears above
the key row. Tap one to replace the word. On a keyboard, **Tab** completes. Options turns it off.

## Re-running an entry

Tap the **>** before an entry to copy it and, if the input is empty, put it back in the box.
Options sets whether it copies, fills, or both.

## Docs

This tab shows the doc you read last. Tap the tab again for the others, as chips; tap one to
switch. Each doc keeps its place. The round **≡** button jumps to a section: an installed app has
no find-in-page.

## Sessions

The **log** tab keeps every session. Open one to rename it, delete it, or copy it (📋) as
commented source: each entry as it was typed, with what it printed as comments, so it pastes back
in and reruns. Entries that errored are commented out.

## Offline

Everything is cached on first load. An update downloads in the background; a toast offers to
reload, or it applies the next time the app comes back to the foreground.
